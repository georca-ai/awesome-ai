## Escrita e assistentes de uso geral

- [ChatGPT](https://chatgpt.com/) — Escreva e revise textos, explore ideias e faça perguntas complementares.
- [Claude](https://claude.com/product/overview) — Analise documentos longos e reescreva rascunhos com base em orientações específicas.
- [Gemini](https://gemini.google.com/) — Faça perguntas sobre textos e imagens ou transforme anotações em um primeiro rascunho.
- [Kimi](https://www.kimi.com/) — Envie um documento e pergunte o que quiser saber sobre ele.
- [DeepSeek](https://chat.deepseek.com/) — Um chat para resolver problemas passo a passo e consultar documentos enviados.
- [Qwen Chat](https://chat.qwen.ai/) — Faça perguntas sobre textos e imagens ou redija conteúdo em vários idiomas.

## Programação

- [GitHub Copilot](https://github.com/features/copilot) — Receba sugestões de código e faça perguntas dentro do editor.
- [Cursor](https://cursor.com/) — Explore a base de código e receba sugestões de alterações coordenadas em vários arquivos.
- [Continue](https://github.com/continuedev/continue) — Configure a assistência de programação com o modelo que preferir.
- [OpenAI Codex](https://github.com/openai/codex) — Peça uma mudança no código pelo terminal e deixe o Codex rodar as verificações do projeto.
- [Claude Code](https://code.claude.com/docs/en/overview) — Converse com o Claude no terminal para ler o código, editar arquivos e rodar testes.
- [Google Antigravity](https://antigravity.google/) — Use agentes de programação no editor, no terminal e no navegador para implementar e validar mudanças.
- [OpenCode](https://opencode.ai/) — Use um agente de programação de código aberto no terminal com o provedor de modelos de sua escolha.
- [v0](https://v0.app/docs) — Gere interfaces web a partir de instruções ou protótipos e ajuste-as em uma prévia ao vivo.
- [Lovable](https://docs.lovable.dev/introduction/welcome) — Crie e publique aplicações web a partir de uma descrição em linguagem natural.
- [Bolt.new](https://bolt.new/) — Gere, edite e execute aplicações web full stack no navegador.

## Busca e pesquisa

- [Perplexity](https://www.perplexity.ai/) — Pesquise na web e confira a resposta pelos links das fontes.
- [NotebookLM](https://notebook.google.com/) — Faça perguntas e prepare anotações de estudo usando as fontes que você reuniu.
- [Elicit](https://elicit.com/) — Encontre artigos científicos e reúna os resultados em uma tabela comparativa.
- [Exa](https://exa.ai/) — Recupere páginas relevantes e seus textos por meio de uma API de busca.
- [Tavily](https://www.tavily.com/) — Adicione busca na web e extração de conteúdo a agentes e fluxos de pesquisa.
- [Consensus](https://consensus.app/) — Busque literatura revisada por pares e siga as citações até os estudos que embasam o resumo.

## Imagem e design

- [Adobe Firefly](https://firefly.adobe.com/) — Crie conceitos visuais e preencha ou substitua áreas selecionadas de uma imagem.
- [Ideogram](https://ideogram.ai/) — Crie imagens com texto integrado para cartazes e peças gráficas.
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — Monte fluxos reutilizáveis de geração de imagens em um editor de nós.
- [Recraft](https://www.recraft.ai/) — Gere e edite ilustrações vetoriais, ícones e outros recursos gráficos.
- [Figma Make](https://www.figma.com/make/) — Transforme instruções ou designs existentes do Figma em protótipos interativos.
- [FLUX](https://bfl.ai/) — Gere e edite imagens com os modelos da Black Forest Labs por meio de uma API.
- [Kite](https://kite.new/) — Desenhe telas com sua equipe enquanto agentes de IA como Claude ou Cursor criam camadas editáveis no mesmo arquivo via MCP.

## Áudio e vídeo

- [Whisper](https://github.com/openai/whisper) — Transcreva gravações localmente com um modelo de fala de código aberto.
- [ElevenLabs](https://elevenlabs.io/) — Transforme roteiros em narrações e produza áudio dublado.
- [Runway](https://runway.com/) — Gere clipes de vídeo a partir de instruções em texto ou imagens estáticas.
- [Kling AI](https://www.klingai.com/) — Crie vídeos curtos a partir de texto ou imagens e use referências para orientar o movimento.
- [Veo](https://deepmind.google/models/veo/) — Crie vídeos com som a partir de uma descrição ou de uma imagem de referência.
- [Descript](https://www.descript.com/) — Transcreva gravações e edite áudio ou vídeo alterando a transcrição.

## Produtividade e automação

- [Notion AI](https://www.notion.com/product/ai) — Resuma anotações e esboce documentos no seu espaço de trabalho do Notion.
- [Zapier AI](https://zapier.com/ai) — Adicione etapas de classificação ou resumo de textos a automações entre aplicativos.
- [n8n](https://n8n.io/) — Conecte aplicativos, APIs e modelos de linguagem em um editor visual de fluxos.
- [Dify](https://github.com/langgenius/dify) — Crie aplicativos de IA com fluxos que recuperam informações das suas próprias bases de conhecimento.
- [Flowise](https://github.com/FlowiseAI/Flowise) — Conecte modelos e ferramentas em um editor visual para criar agentes de IA.
- [Browser Use](https://github.com/browser-use/browser-use) — Use uma biblioteca Python para automatizar tarefas no navegador, como ler páginas e preencher formulários.
- [Manus](https://manus.im/) — Peça uma pesquisa na web e receba os resultados em um relatório.
