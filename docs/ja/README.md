## 文章作成と汎用アシスタント

- [ChatGPT](https://chatgpt.com/) — 文章の下書きや推敲、アイデア出しを対話しながら進める。
- [Claude](https://claude.com/product/overview) — 長い文書を読み解き、具体的な指示に沿って下書きを書き直す。
- [Gemini](https://gemini.google.com/) — テキストや画像について質問し、メモを下書きにまとめる。
- [Kimi](https://www.kimi.com/) — 資料をアップロードし、知りたいことを直接聞ける。
- [DeepSeek](https://chat.deepseek.com/) — 資料を読み込んだり、筋道を立てて問題を考えたりできるチャット。
- [Qwen Chat](https://chat.qwen.ai/) — テキストや画像について質問し、複数の言語で文章を下書きする。

## プログラミング

- [GitHub Copilot](https://github.com/features/copilot) — エディター内でコード補完を受けたり、コードについて質問したりする。
- [Cursor](https://cursor.com/) — コードベースを調べながら、複数ファイルにまたがる修正案を受け取る。
- [Continue](https://github.com/continuedev/continue) — 使いたいモデルを選び、開発支援の設定を調整する。
- [OpenAI Codex](https://github.com/openai/codex) — ターミナルで変更内容を伝えると、コードの修正から動作確認まで進めてくれる。
- [Claude Code](https://code.claude.com/docs/en/overview) — ターミナルで会話しながらコードを調べ、ファイルの修正やテストを任せられる。
- [Google Antigravity](https://antigravity.google/) — エディター、ターミナル、ブラウザーを横断してエージェントに実装や動作確認を任せる。
- [OpenCode](https://opencode.ai/) — モデル提供元を選んで、オープンソースのコーディングエージェントをターミナルで使う。
- [v0](https://v0.app/docs) — 指示文やモックアップからウェブ画面を生成し、ライブプレビューで調整する。
- [Lovable](https://docs.lovable.dev/introduction/welcome) — 自然言語で要件を伝え、ウェブアプリを作成して公開する。
- [Bolt.new](https://bolt.new/) — ブラウザー上でフルスタックのウェブアプリを生成、編集、実行する。

## 検索とリサーチ

- [Perplexity](https://www.perplexity.ai/) — ウェブ検索の回答を得て、引用元のリンクから内容を確かめる。
- [NotebookLM](https://notebook.google.com/) — 集めた資料に基づいて質問し、学習ノートをまとめる。
- [Elicit](https://elicit.com/) — 関連論文を探し、研究結果を比較表に整理する。
- [Exa](https://exa.ai/) — 検索APIで関連ページを探し、本文を取得する。
- [Tavily](https://www.tavily.com/) — エージェントや調査フローにウェブ検索と本文抽出を組み込む。
- [Consensus](https://consensus.app/) — 査読済み文献を検索し、要約の根拠となる研究を引用からたどる。

## 画像とデザイン

- [Adobe Firefly](https://firefly.adobe.com/) — 画像のアイデアを形にし、選択範囲を補完したり置き換えたりする。
- [Ideogram](https://ideogram.ai/) — 文字を組み込んだポスターやグラフィックを作る。
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — ノードエディターで再利用できる画像生成ワークフローを組む。
- [Recraft](https://www.recraft.ai/) — ベクターイラストやアイコンなどのデザイン素材を生成、編集する。
- [Figma Make](https://www.figma.com/make/) — 指示文や既存のFigmaデザインから操作できるプロトタイプを作る。
- [FLUX](https://bfl.ai/) — Black Forest LabsのモデルをAPIから使い、画像を生成、編集する。
- [Kite](https://kite.new/) — チームと一緒に画面をデザインし、Claude や Cursor などの AI エージェントが MCP 経由で同じファイルに編集可能なレイヤーを描きます。

## 音声と動画

- [Whisper](https://github.com/openai/whisper) — オープンソースの音声モデルで録音をローカルに文字起こしする。
- [ElevenLabs](https://elevenlabs.io/) — 台本からナレーションを作り、吹き替え音声を制作する。
- [Runway](https://runway.com/) — テキストの指示や静止画をもとに短い動画を作る。
- [Kling AI](https://www.klingai.com/) — テキストや静止画から動画を作り、参考素材で動きを指定できる。
- [Veo](https://deepmind.google/models/veo/) — 文章や参考画像から音声付きの短い動画を作れる。
- [Descript](https://www.descript.com/) — 録音を書き起こし、そのテキストを編集して音声や動画をカットする。

## 業務効率化と自動化

- [Notion AI](https://www.notion.com/product/ai) — Notion のワークスペース内でメモを要約し、文書の下書きを作る。
- [Zapier AI](https://zapier.com/ai) — アプリをまたぐ自動処理に、テキストの分類や要約を組み込む。
- [n8n](https://n8n.io/) — ビジュアルエディターでアプリや API、言語モデルをつないで自動化する。
- [Dify](https://github.com/langgenius/dify) — 独自のナレッジベースから情報を検索するワークフローでAIアプリを構築する。
- [Flowise](https://github.com/FlowiseAI/Flowise) — ビジュアルエディターでモデルとツールをつなぎ、AIエージェントを作る。
- [Browser Use](https://github.com/browser-use/browser-use) — Pythonライブラリでページの読み取りやフォーム入力などのブラウザー作業を自動化する。
- [Manus](https://manus.im/) — ウェブでの情報収集から、結果をレポートにまとめるところまで任せられる。
