## 写作与通用助手

- [ChatGPT](https://chatgpt.com/) — 起草和修改文稿、梳理思路，并通过追问深入探讨。
- [Claude](https://claude.com/product/overview) — 阅读长文档，根据具体反馈修改草稿。
- [Gemini](https://gemini.google.com/) — 围绕文字和图片提问，或把笔记整理成初稿。

## 编程

- [GitHub Copilot](https://github.com/features/copilot) — 在编辑器中获取代码补全建议，并围绕当前代码提问。
- [Cursor](https://cursor.com/) — 在编辑器中浏览代码库，并获取跨文件的修改建议。
- [Continue](https://github.com/continuedev/continue) — 配置适合自己的编程助手，并自行选择模型。

## 搜索与研究

- [Perplexity](https://www.perplexity.ai/) — 搜索网页，并沿引用链接核对答案。
- [NotebookLM](https://notebook.google.com/) — 基于自己收集的资料提问、整理学习笔记。
- [Elicit](https://elicit.com/) — 寻找相关论文，并将研究结果提取到对照表中。

## 图像与设计

- [Adobe Firefly](https://firefly.adobe.com/) — 生成图像构思，并填充或替换图片中的选定区域。
- [Ideogram](https://ideogram.ai/) — 生成带文字的海报和配图。
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — 用节点编辑器搭建可重复使用的图像生成流程。

## 音视频

- [Whisper](https://github.com/openai/whisper) — 用开源语音模型在本地转录录音。
- [ElevenLabs](https://elevenlabs.io/) — 把文稿转成旁白，并制作配音音轨。
- [Runway](https://runway.com/) — 用文字提示或静态图片生成短视频片段。

## 生产力与自动化

- [Notion AI](https://www.notion.com/product/ai) — 在 Notion 工作区中总结笔记并起草文档。
- [Zapier AI](https://zapier.com/ai) — 在跨应用的自动化流程中加入文本分类或摘要步骤。
- [n8n](https://n8n.io/) — 在可视化编辑器中连接应用、API 和语言模型。
