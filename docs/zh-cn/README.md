## 写作与通用助手

- [ChatGPT](https://chatgpt.com/) — 适合拿来想点子、起草文章，再按反馈逐段改。
- [Claude](https://claude.com/product/overview) — 适合读长文，也能按具体意见改稿。
- [Gemini](https://gemini.google.com/) — 可以对着图片提问，也能把零散笔记写成初稿。
- [Kimi](https://www.kimi.com/) — 上传文档后，直接问你想找的信息。
- [DeepSeek](https://chat.deepseek.com/) — 可上传文档，也适合一步步推演问题。
- [Qwen Chat](https://chat.qwen.ai/) — 可以问图里有什么，也可以让它用不同语言写稿。

## 编程

- [GitHub Copilot](https://github.com/features/copilot) — 写代码时会在编辑器里给出补全建议，也可以就手头的代码提问。
- [Cursor](https://cursor.com/) — 在编辑器里找代码，或让它一次修改几个相关文件。
- [Continue](https://github.com/continuedev/continue) — 可自己选模型、配助手的编程工具。
- [OpenAI Codex](https://github.com/openai/codex) — 在终端里说明要改什么，Codex 会修改代码并运行项目检查。
- [Claude Code](https://code.claude.com/docs/en/overview) — 在终端里和 Claude 对话，让它读代码、改文件、跑测试。
- [Google Antigravity](https://antigravity.google/) — 编程代理能操作编辑器、终端和浏览器，写完代码可以直接验证。
- [OpenCode](https://opencode.ai/) — 开源的终端编程助手，可自己选模型服务。
- [v0](https://v0.app/docs) — 给一段描述或一张设计稿，生成网页界面后可以边看预览边改。
- [Lovable](https://docs.lovable.dev/introduction/welcome) — 用几句话描述需求，就能生成并发布网页应用。
- [Bolt.new](https://bolt.new/) — 在浏览器里写、改、跑一个全栈应用。

## 搜索与研究

- [Perplexity](https://www.perplexity.ai/) — 搜网页时会给出带来源的答案，方便点回原文。
- [NotebookLM](https://notebook.google.com/) — 把自己的资料放进去，就能围绕它们提问、整理笔记。
- [Elicit](https://elicit.com/) — 找论文，把各篇的研究结果拉到一张表里对照。
- [Exa](https://exa.ai/) — 用 API 搜网页，也可以拿到网页正文。
- [Tavily](https://www.tavily.com/) — 给智能体加上网页搜索和正文提取。
- [Consensus](https://consensus.app/) — 从同行评审文献里找答案，点引用就能看原研究。

## 图像与设计

- [Adobe Firefly](https://firefly.adobe.com/) — 可以从头出图，也可以圈一块区域填补或替换。
- [Ideogram](https://ideogram.ai/) — 适合做带字的海报和配图。
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — 把生成图片的步骤连成节点，下次可以直接复用。
- [Recraft](https://www.recraft.ai/) — 做矢量插画、图标，也能接着编辑。
- [Figma Make](https://www.figma.com/make/) — 拿一张 Figma 设计稿或一段描述，做成能点的原型。
- [FLUX](https://bfl.ai/) — Black Forest Labs 的图像模型，可通过 API 出图或改图。
- [Kite](https://kite.new/) — 与团队一起设计界面，Claude、Cursor 等 AI 智能体通过 MCP 在同一文件中绘制可编辑图层。

## 音视频

- [Whisper](https://github.com/openai/whisper) — 在本地把录音转成文字。
- [ElevenLabs](https://elevenlabs.io/) — 把稿子读成旁白，也能做配音。
- [Runway](https://runway.com/) — 用一句描述或一张静态图做短片。
- [Kling AI](https://www.klingai.com/) — 用文字或图片做短片，也可以用参考素材指定动作。
- [Veo](https://deepmind.google/models/veo/) — 输入一段描述或给一张参考图，生成带声音的短片。
- [Descript](https://www.descript.com/) — 改逐字稿就能剪音视频，删掉一段文字，对应片段也会剪掉。

## 生产力与自动化

- [Notion AI](https://www.notion.com/product/ai) — 在 Notion 里把笔记整理成摘要或文档初稿。
- [Zapier AI](https://zapier.com/ai) — 给跨应用的自动化加上文本分类或摘要。
- [n8n](https://n8n.io/) — 用可视化编辑器把应用、API 和模型接起来。
- [Dify](https://github.com/langgenius/dify) — 可以接上自己的知识库，搭一个会查资料的 AI 应用。
- [Flowise](https://github.com/FlowiseAI/Flowise) — 把模型和工具拖到画布上连起来，就能搭一个智能体。
- [Browser Use](https://github.com/browser-use/browser-use) — Python 库，可以让浏览器自动读网页、填表。
- [Manus](https://manus.im/) — 可以把查资料和写报告一起交给它做。
