## Redacción y asistentes generales

- [ChatGPT](https://chatgpt.com/) — Redacta y revisa textos, explora ideas y haz preguntas de seguimiento.
- [Claude](https://claude.com/product/overview) — Revisa documentos largos y reescribe borradores siguiendo indicaciones concretas.
- [Gemini](https://gemini.google.com/) — Haz preguntas sobre textos e imágenes o convierte apuntes en un primer borrador.
- [Kimi](https://www.kimi.com/) — Sube un documento y pregunta por los datos que necesitas.
- [DeepSeek](https://chat.deepseek.com/) — Un chat para razonar paso a paso y consultar documentos que hayas subido.
- [Qwen Chat](https://chat.qwen.ai/) — Haz preguntas sobre textos e imágenes o redacta contenido en varios idiomas.

## Programación

- [GitHub Copilot](https://github.com/features/copilot) — Obtén sugerencias de código y haz preguntas desde el editor.
- [Cursor](https://cursor.com/) — Explora una base de código y recibe propuestas de cambios coordinados en varios archivos.
- [Continue](https://github.com/continuedev/continue) — Configura la asistencia de programación con el modelo que elijas.
- [OpenAI Codex](https://github.com/openai/codex) — Pide un cambio de código desde la terminal y deja que Codex ejecute las comprobaciones del proyecto.
- [Claude Code](https://code.claude.com/docs/en/overview) — Desde la terminal puedes pedirle a Claude que lea el código, edite archivos y ejecute pruebas.
- [Google Antigravity](https://antigravity.google/) — Usa agentes de programación en el editor, la terminal y el navegador para implementar y verificar cambios.
- [OpenCode](https://opencode.ai/) — Usa un agente de programación de código abierto en la terminal con el proveedor de modelos que elijas.
- [v0](https://v0.app/docs) — Genera interfaces web a partir de instrucciones o bocetos y ajústalas en una vista previa en directo.
- [Lovable](https://docs.lovable.dev/introduction/welcome) — Crea y publica aplicaciones web a partir de una descripción en lenguaje natural.
- [Bolt.new](https://bolt.new/) — Genera, edita y ejecuta aplicaciones web de pila completa en el navegador.

## Búsqueda e investigación

- [Perplexity](https://www.perplexity.ai/) — Busca en la web y consulta las fuentes para comprobar la respuesta.
- [NotebookLM](https://notebook.google.com/) — Haz preguntas y prepara apuntes de estudio con las fuentes que recopiles.
- [Elicit](https://elicit.com/) — Encuentra artículos científicos y reúne sus resultados en una tabla comparativa.
- [Exa](https://exa.ai/) — Recupera páginas web relevantes y su texto mediante una API de búsqueda.
- [Tavily](https://www.tavily.com/) — Añade búsqueda web y extracción de contenido a agentes y flujos de investigación.
- [Consensus](https://consensus.app/) — Busca literatura revisada por pares y sigue las citas hasta los estudios en que se basa un resumen.

## Imagen y diseño

- [Adobe Firefly](https://firefly.adobe.com/) — Genera conceptos visuales y rellena o sustituye zonas seleccionadas de una imagen.
- [Ideogram](https://ideogram.ai/) — Crea imágenes con texto integrado para carteles y gráficos.
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — Construye flujos reutilizables de generación de imágenes con un editor de nodos.
- [Recraft](https://www.recraft.ai/) — Genera y edita ilustraciones vectoriales, iconos y otros recursos gráficos.
- [Figma Make](https://www.figma.com/make/) — Convierte instrucciones o diseños existentes de Figma en prototipos interactivos.
- [FLUX](https://bfl.ai/) — Genera y edita imágenes con los modelos de Black Forest Labs mediante una API.

## Audio y vídeo

- [Whisper](https://github.com/openai/whisper) — Transcribe grabaciones de forma local con un modelo de voz de código abierto.
- [ElevenLabs](https://elevenlabs.io/) — Convierte guiones en narraciones habladas y produce audio doblado.
- [Runway](https://runway.com/) — Genera clips de vídeo a partir de indicaciones de texto o imágenes fijas.
- [Kling AI](https://www.klingai.com/) — Crea vídeos cortos a partir de texto o imágenes y usa referencias para marcar el movimiento.
- [Veo](https://deepmind.google/models/veo/) — Crea vídeos con sonido a partir de una descripción o una imagen de referencia.
- [Descript](https://www.descript.com/) — Transcribe grabaciones y edita audio o vídeo modificando la transcripción.

## Productividad y automatización

- [Notion AI](https://www.notion.com/product/ai) — Resume notas y redacta documentos dentro de tu espacio de trabajo de Notion.
- [Zapier AI](https://zapier.com/ai) — Añade pasos de clasificación o resumen de textos a automatizaciones entre aplicaciones.
- [n8n](https://n8n.io/) — Conecta aplicaciones, API y modelos de lenguaje en un editor visual de flujos.
- [Dify](https://github.com/langgenius/dify) — Crea aplicaciones de IA con flujos que recuperan información de tus propias bases de conocimiento.
- [Flowise](https://github.com/FlowiseAI/Flowise) — Conecta modelos y herramientas en un editor visual para crear agentes de IA.
- [Browser Use](https://github.com/browser-use/browser-use) — Usa una biblioteca de Python para automatizar tareas del navegador como leer páginas y rellenar formularios.
- [Manus](https://manus.im/) — Encárgale una búsqueda en la web y recibe los resultados en un informe.
