## 寫作與通用助理

- [ChatGPT](https://chatgpt.com/) — 撰寫和修改文稿、腦力激盪，並透過追問深入探討。
- [Claude](https://claude.com/product/overview) — 閱讀長篇文件，並依照具體回饋修改草稿。
- [Gemini](https://gemini.google.com/) — 針對文字和圖片提問，或將筆記整理成初稿。

<a name="category-coding"></a>

## 程式設計

- [GitHub Copilot](https://github.com/features/copilot) — 在編輯器中取得程式碼補全建議，並針對目前的程式碼提問。
- [Cursor](https://cursor.com/) — 在編輯器中瀏覽程式碼庫，並取得跨檔案的修改建議。
- [Continue](https://github.com/continuedev/continue) — 設定符合需求的程式設計助理，並自行選擇模型。

<a name="category-research"></a>

## 搜尋與研究

- [Perplexity](https://www.perplexity.ai/) — 搜尋網頁，並透過引用連結查核答案。
- [NotebookLM](https://notebook.google.com/) — 依據自行收集的資料提問並整理學習筆記。
- [Elicit](https://elicit.com/) — 尋找相關論文，並將研究結果整理成比較表。

<a name="category-image"></a>

## 圖像與設計

- [Adobe Firefly](https://firefly.adobe.com/) — 產生圖像構想，並填補或取代圖片中的選取區域。
- [Ideogram](https://ideogram.ai/) — 產生帶有文字的海報和圖像素材。
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — 用節點編輯器建立可重複使用的圖像生成流程。

<a name="category-media"></a>

## 音訊與影片

- [Whisper](https://github.com/openai/whisper) — 用開源語音模型在本機轉錄錄音。
- [ElevenLabs](https://elevenlabs.io/) — 將文稿轉成旁白，並製作配音音軌。
- [Runway](https://runway.com/) — 用文字提示或靜態圖片生成短影片片段。

<a name="category-automation"></a>

## 生產力與自動化

- [Notion AI](https://www.notion.com/product/ai) — 在 Notion 工作區內摘要筆記並撰寫文件草稿。
- [Zapier AI](https://zapier.com/ai) — 在跨應用程式的自動化流程中加入文字分類或摘要步驟。
- [n8n](https://n8n.io/) — 在視覺化編輯器中串接應用程式、API 和語言模型。
