## 寫作與通用助理

- [ChatGPT](https://chatgpt.com/) — 撰寫和修改文稿、腦力激盪，並透過追問深入探討。
- [Claude](https://claude.com/product/overview) — 閱讀長篇文件，並依照具體回饋修改草稿。
- [Gemini](https://gemini.google.com/) — 針對文字和圖片提問，或將筆記整理成初稿。
- [Kimi](https://www.kimi.com/) — 上傳文件後，直接問你想找的資訊。
- [DeepSeek](https://chat.deepseek.com/) — 可以上傳文件，也能一步步推敲問題。
- [Qwen Chat](https://chat.qwen.ai/) — 針對文字和圖片提問，或用多種語言起草內容。

## 程式設計

- [GitHub Copilot](https://github.com/features/copilot) — 在編輯器中取得程式碼補全建議，並針對目前的程式碼提問。
- [Cursor](https://cursor.com/) — 在編輯器中瀏覽程式碼庫，並取得跨檔案的修改建議。
- [Continue](https://github.com/continuedev/continue) — 設定符合需求的程式設計助理，並自行選擇模型。
- [OpenAI Codex](https://github.com/openai/codex) — 在終端機說明想改什麼，Codex 會修改程式碼並執行專案檢查。
- [Claude Code](https://code.claude.com/docs/en/overview) — 在終端機和 Claude 對話，讓它讀程式碼、改檔案、跑測試。
- [Google Antigravity](https://antigravity.google/) — 讓程式代理在編輯器、終端機和瀏覽器中開發並驗證修改。
- [OpenCode](https://opencode.ai/) — 使用開源終端機程式代理，並自行選擇模型供應商。
- [v0](https://v0.app/docs) — 用提示詞或設計稿產生網頁介面，再透過即時預覽調整。
- [Lovable](https://docs.lovable.dev/introduction/welcome) — 用自然語言描述需求，產生並發布網頁應用程式。
- [Bolt.new](https://bolt.new/) — 在瀏覽器內產生、編輯和執行全端網頁應用程式。

## 搜尋與研究

- [Perplexity](https://www.perplexity.ai/) — 搜尋網頁，並透過引用連結查核答案。
- [NotebookLM](https://notebook.google.com/) — 依據自行收集的資料提問並整理學習筆記。
- [Elicit](https://elicit.com/) — 尋找相關論文，並將研究結果整理成比較表。
- [Exa](https://exa.ai/) — 透過搜尋 API 查找相關網頁並取得正文。
- [Tavily](https://www.tavily.com/) — 為代理和研究流程接入網頁搜尋與內容擷取。
- [Consensus](https://consensus.app/) — 搜尋同儕審查文獻，並沿引用查閱摘要所依據的研究。

## 圖像與設計

- [Adobe Firefly](https://firefly.adobe.com/) — 產生圖像構想，並填補或取代圖片中的選取區域。
- [Ideogram](https://ideogram.ai/) — 產生帶有文字的海報和圖像素材。
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — 用節點編輯器建立可重複使用的圖像生成流程。
- [Recraft](https://www.recraft.ai/) — 產生和編輯向量插畫、圖示等設計素材。
- [Figma Make](https://www.figma.com/make/) — 把提示詞或現有 Figma 設計稿變成互動原型。
- [FLUX](https://bfl.ai/) — 透過 API 呼叫 Black Forest Labs 的模型產生和編輯影像。
- [Kite](https://kite.new/) — 與團隊一起設計介面，Claude、Cursor 等 AI 代理透過 MCP 在同一檔案中繪製可編輯圖層。

## 音訊與影片

- [Whisper](https://github.com/openai/whisper) — 用開源語音模型在本機轉錄錄音。
- [ElevenLabs](https://elevenlabs.io/) — 將文稿轉成旁白，並製作配音音軌。
- [Runway](https://runway.com/) — 用文字提示或靜態圖片生成短影片片段。
- [Kling AI](https://www.klingai.com/) — 用文字或圖片做短片，也可以用參考素材指定動作。
- [Veo](https://deepmind.google/models/veo/) — 給一段描述或一張參考圖，就能產生有聲短片。
- [Descript](https://www.descript.com/) — 轉錄錄音，透過修改逐字稿剪輯音訊或影片。

## 生產力與自動化

- [Notion AI](https://www.notion.com/product/ai) — 在 Notion 工作區內摘要筆記並撰寫文件草稿。
- [Zapier AI](https://zapier.com/ai) — 在跨應用程式的自動化流程中加入文字分類或摘要步驟。
- [n8n](https://n8n.io/) — 在視覺化編輯器中串接應用程式、API 和語言模型。
- [Dify](https://github.com/langgenius/dify) — 建置 AI 應用，透過工作流程從自己的知識庫檢索資料。
- [Flowise](https://github.com/FlowiseAI/Flowise) — 在視覺化編輯器中連接模型和工具，建置 AI 代理。
- [Browser Use](https://github.com/browser-use/browser-use) — 用 Python 函式庫自動完成讀取網頁、填寫表單等瀏覽器操作。
- [Manus](https://manus.im/) — 可以把查資料和寫報告一起交給它做。
