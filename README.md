## Writing and general assistants

- [ChatGPT](https://chatgpt.com/) — Draft and revise text, brainstorm ideas, and ask follow-up questions.
- [Claude](https://claude.com/product/overview) — Read through a long document or revise a draft from detailed feedback.
- [Gemini](https://gemini.google.com/) — Ask questions about text and images or turn notes into a first draft.
- [Kimi](https://www.kimi.com/) — Upload a document and ask Kimi to pull out the details you need.
- [DeepSeek](https://chat.deepseek.com/) — A chat assistant for working through reasoning problems and discussing uploaded documents.
- [Qwen Chat](https://chat.qwen.ai/) — Ask questions about text and images, or draft content in multiple languages.

## Coding

- [GitHub Copilot](https://github.com/features/copilot) — Get inline code suggestions and ask questions inside your editor.
- [Cursor](https://cursor.com/) — An editor that can find its way around your codebase and make changes across several files.
- [Continue](https://github.com/continuedev/continue) — A configurable coding assistant that lets you bring your own model.
- [OpenAI Codex](https://github.com/openai/codex) — Ask for a code change and have Codex run the project checks from your terminal.
- [Claude Code](https://code.claude.com/docs/en/overview) — Inspect a repo, edit files, and run tests from a terminal chat.
- [Google Antigravity](https://antigravity.google/) — Use coding agents across an editor, terminal, and browser to build and verify changes.
- [OpenCode](https://opencode.ai/) — An open-source terminal coding agent with a choice of model providers.
- [v0](https://v0.app/docs) — Start with a prompt or mockup, then refine the web interface in a live preview.
- [Lovable](https://docs.lovable.dev/introduction/welcome) — Describe the web app you want to build, then publish it from Lovable.
- [Bolt.new](https://bolt.new/) — Build and run a full-stack web app without leaving the browser.

## Search and research

- [Perplexity](https://www.perplexity.ai/) — Search the web and check the answer against the linked sources.
- [NotebookLM](https://notebook.google.com/) — Give it your own sources and ask questions or turn them into study notes.
- [Elicit](https://elicit.com/) — Find papers and put their findings side by side in a table.
- [Exa](https://exa.ai/) — Retrieve relevant web pages and page text through a search API.
- [Tavily](https://www.tavily.com/) — Add web search and page extraction to agents and research workflows.
- [Consensus](https://consensus.app/) — Find answers in peer-reviewed papers and use the citations to check the original studies.

## Images and design

- [Adobe Firefly](https://firefly.adobe.com/) — Generate image concepts and fill or replace selected areas of an image.
- [Ideogram](https://ideogram.ai/) — An image generator for posters and other graphics that need text.
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — Build reusable image generation workflows with a node editor.
- [Recraft](https://www.recraft.ai/) — Make and edit vector graphics such as icons and illustrations.
- [Figma Make](https://www.figma.com/make/) — Start with a prompt or a Figma design and turn it into a clickable prototype.
- [FLUX](https://bfl.ai/) — Generate and edit images with Black Forest Labs models via an API.
- [Kite](https://kite.new/) — Design screens with your team while AI agents like Claude or Cursor draw editable layers in the same file over MCP.

## Audio and video

- [Whisper](https://github.com/openai/whisper) — Turn a recording into text locally with an open-source speech model.
- [ElevenLabs](https://elevenlabs.io/) — Turn scripts into spoken narration and produce dubbed audio.
- [Runway](https://runway.com/) — Generate short video clips from text prompts or still images.
- [Kling AI](https://www.klingai.com/) — Make a clip from text or a still image, with references to guide the motion.
- [Veo](https://deepmind.google/models/veo/) — Generate video with sound from a prompt or reference image.
- [Descript](https://www.descript.com/) — Edit a transcript to cut the corresponding audio or video.

## Productivity and automation

- [Notion AI](https://www.notion.com/product/ai) — Summarize notes and draft documents within your Notion workspace.
- [Zapier AI](https://zapier.com/ai) — Add steps that classify or summarize text to automations across apps.
- [n8n](https://n8n.io/) — Connect apps, APIs, and language models in a visual workflow editor.
- [Dify](https://github.com/langgenius/dify) — Build an AI app that can look up information in your own knowledge base.
- [Flowise](https://github.com/FlowiseAI/Flowise) — Wire up models and tools on a canvas to build an agent.
- [Browser Use](https://github.com/browser-use/browser-use) — A Python library for browser tasks such as reading pages and filling out forms.
- [Manus](https://manus.im/) — Hand off web research and get the findings back as a report.
